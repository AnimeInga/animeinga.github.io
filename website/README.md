# AnimeIngá Site

Site oficial do AnimeIngá, construído com Docusaurus 3.10.2, React 19 e MUI 6.

## Scripts

- `npm start` — Inicia o servidor de desenvolvimento.
- `npm run build` — Gera os arquivos estáticos de produção.
- `npm run serve` — Serve o build localmente.

## Estrutura

- `src/pages/index.tsx` — Landing page provisória da edição atual.
- `src/theme/Root.tsx` — Provedor do tema MUI.
- `src/css/custom.css` — Variáveis e estilos globais.
- `static/` — Assets estáticos (logo, favicon, CNAME).
